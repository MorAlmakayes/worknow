# Board inbox

Instructions from the board (Mor). The CEO / decision agent reads this at the start of every run and treats entries as authoritative.

## How to use

Add a new entry at the top. Keep entries short and actionable. Mark status when done or superseded.

| Field | Meaning |
|-------|---------|
| Date | Local date (Asia/Jerusalem) |
| From | Board |
| Instruction | What to do or decide |
| Status | `open` · `in_progress` · `done` · `superseded` |
